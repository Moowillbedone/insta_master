# 협업 제안서

**언제 쓰나**
- `status`가 '회신' 또는 '협의'이고, 브리프(08)를 받은 뒤에 쓴다.
- 견적서(05)를 함께 보낸다. 제안서 7장은 요약이고, 상세 금액은 견적서에 둔다.

**작성 규칙**
- 순서를 바꾸지 않는다: 브랜드 이해 → 제안 콘셉트 3안 → 납품물 → 일정 → 표시·준수 → 성과 리포트 → 비용 구조.
- 1장 '브랜드 이해'는 브랜드가 브리프에서 준 정보와 공식 페이지만으로 쓴다. 추측한 매출이나 고객 데이터를 쓰지 않는다.
- 콘셉트 3안은 도하 시리즈 기둥(`pillar`: 돌려입기, 컬러공식, 비율, 상황별, 아이템가이드)에서 고른다 (content/SCHEMA.md).
- 모든 문장은 제안형으로 쓴다: "이렇게 매치하면 ~". 체험형("입어 보니")은 쓰지 않는다 (brand/doha.yaml `voice.rules`).
- 지표는 미디어킷과 같은 실제 값만, 기준일과 함께 쓴다. 예상 도달이나 예상 판매를 약속하지 않는다.
- 금액은 docs/01-monetization-playbook.md 4-2 워크시트로 계산한다.
- 파트너십 광고 권한은 도하가 프로페셔널 계정으로 전환한 뒤에만 넣는다 (근거: docs/research/sponsorship-kr.md §6 [주장]).
- 화면에서 지울 안내는 `‹ ›`로 표시했다. 보내기 전에 지운다.

**5장 '표시·준수'의 근거**
- 가상인물 표시 (사진·영상은 인물 가까이, 2026-06-01 시행) [확인]: docs/research/kr-compliance.md §1-5
- 캡션 첫 줄과 이미지 안 표시, '더보기'·댓글 표시는 부적절 [확인]: docs/research/kr-compliance.md §1-2
- 릴스는 시작과 끝에 표시 [확인]: docs/research/kr-compliance.md §1-2
- 표시 문구 형식 (해석): docs/research/kr-compliance.md §1-3, §7. 게시 단계의 캡션 템플릿은 docs/04-compliance-checklist.md §3(협찬)·§4(유료 광고)와 같게 쓴다.
- AI 이미지와 실물 차이 안내 (해석): docs/research/kr-compliance.md §4-1
- 상업 이용 허가 음원 (해석): docs/research/kr-compliance.md §5-4
- 효능 문구는 브랜드 제공·브랜드 책임 (해석): docs/research/sponsorship-kr.md §5-2

| 안 | 콘셉트 | 구성 | 맞는 목표 |

| A | {예: "{아이템} 한 벌로 출근룩 3가지" (돌려입기)} | {예: 월·수·금 상의만 바꾸기 / 오피스 로비·성수동 거리} | {예: 저장} |

- 원본 파일과 도하 캐릭터의 권리는 운영자가 가집니다. 브랜드에는 7장의 매체·기간 동안 이용을 허락합니다.

## 5. 표시·준수

| 위치 | 표시 | 비고 |
|---|---|---|
| 캡션 첫 두 줄 | "[광고 · {브랜드명}] AI 기반으로 생성된 가상인물이 포함된 게시물입니다." / "{브랜드명}(으)로부터 {원고료 · 제작비 · 원고료와 제품}을(를) 받아 제작한 게시물입니다." | '더 보기' 전에 보이는 위치. 최종 문구는 승인 단계에서 확인 |
| 도하가 나오는 모든 장·장면 | "AI 가상인물" 배지 (인물 가까이) | |
| 커버 이미지 | "광고" 또는 "협찬" | |
| 인스타그램 | '유료 파트너십' 라벨로 @{브랜드 계정} 태그 | |
| 릴스 | 시작과 끝에 광고 자막, 도하가 나오는 동안 가상인물 표시, AI 정보 라벨 | |
| 제품 이미지 | "AI 합성 이미지로 실제 제품과 색·핏이 다를 수 있어요. 실물은 브랜드 공식 페이지에서 확인하세요." | |
| 브랜드 채널 사용 시 | {AI 생성 이미지 안내 문구 — 협의} | 사용권 범위 안에서 |

- 도하가 제품을 직접 써 본 것처럼 표현하지 않습니다.
- 소재·실측·가격은 브랜드 공식 정보와 확인일을 함께 씁니다.
- 효능·기능 문구는 브랜드가 제공한 문구만 쓰고, 그 근거는 브랜드가 책임집니다.
- 표시는 빼거나 줄일 수 없습니다.

## 6. 성과 리포트

- 시점: 게시 후 24시간, 7일 ({30일 — 선택})
- 지표: 도달, 조회, 좋아요, 댓글, 저장, 공유, 프로필 방문, 팔로우, 링크 클릭 / 릴스는 평균 시청 시간, 완료율 추가
- 비율: 저장 ÷ 도달, 공유 ÷ 도달
- 인스타그램 인사이트 화면 캡처를 함께 드립니다.
- 리포트는 오가닉(광고 제외) 수치입니다. 파트너십 광고를 집행하시면 광고 성과는 브랜드 광고 관리자 기준으로 봐 주세요.
