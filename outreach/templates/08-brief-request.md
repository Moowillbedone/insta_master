# 브리프 요청 (제작 전 자료 요청)

**언제 쓰나**
- 브랜드가 관심을 보이면(`status`=회신) 바로 보낸다. 제안서(04)와 견적서(05)는 이 답을 받은 뒤 쓴다.
- 무료 시안 1컷을 만들기 전에도 1·2번 항목은 받는다.

**왜 이 항목들이 필요한가**

| 요청 항목 | 이유 | 근거 |
|---|---|---|
| 공식 정보 (가격·소재·실측) + 상세페이지 URL | `post.yaml`의 `products`에 `source_url`과 `checked_at`이 없으면 `python doha.py check`가 실패한다 | content/SCHEMA.md |
| 실물 사진 | 실물·실측 기준으로 생성해야 소비자 오인 위험이 줄어든다 | docs/research/kr-compliance.md §4-1 [보도], (해석) |
| 사용 목적·매체·기간 | 사용권과 파트너십 광고 권한을 따로 견적해야 한다 | docs/research/sponsorship-kr.md §5-2, §6 |
| 금지 표현, 효능 문구 근거 | 효능 문구는 브랜드가 근거를 책임진다 | docs/research/sponsorship-kr.md §5-2 (해석) |
| 승인 절차 | 브랜드 승인 후에만 게시한다 | docs/research/kr-compliance.md §4-1 (해석) |
| 표시 문구 승인 | 광고 표시와 가상인물 표시를 미리 합의한다. 빼거나 줄일 수 없다 | docs/research/kr-compliance.md §1-2, §1-5 [확인] |
| 음원 | 상업 이용 허가가 확인된 음원만 쓴다 | docs/research/kr-compliance.md §5-4 (해석) |
| 현재 촬영 방식·비용 (선택 질문) | 제작비를 비교할 시장 자료가 아직 없다 | docs/01-monetization-playbook.md 4-5 (확인 필요) |

**쓰는 법**
- 협찬(제품만 무상 제공)이면 6번의 `[광고 · …]`를 `[협찬 · …]`으로, 둘째 줄을 "{브랜드명}(으)로부터 제품을 무상으로 제공받아 만든 게시물입니다."로 바꾼다. 돈과 제품을 함께 받으면 `[광고 · …]`다. 문구는 대가 종류에 맞춘다 (근거: docs/research/kr-compliance.md §1-3, docs/04-compliance-checklist.md §0).
- 6번 문구는 예시다. 최종 문구는 `python doha.py preview <slug>`가 만든 `out/caption.txt`와 커버 이미지를 보여 주고 승인받는다.
- 받은 자료는 게시물 폴더에 보관한다. 브랜드 이미지는 생성 참고용으로만 쓰고 그대로 재게시하지 않는다 (근거: docs/research/ig-platform.md §5, 독창성 규칙).

```text
제목: [{브랜드명} × 도하] 제작 전 자료 요청드립니다

안녕하세요, {담당자}님. @doha.dailyfit {운영자 이름}입니다.
관심 가져 주셔서 감사합니다. 정확한 제품 표현과 광고 표시를 위해 아래 자료를 부탁드립니다.
없는 항목은 비워 두셔도 됩니다.

1. 제품 공식 정보 ({제품명})
   - 품번·색상
   - 가격 (정가 / 판매가)과 기준일
   - 소재 혼용률 (상세페이지 표기 기준)
   - 사이즈별 실측 (예: 총장, 어깨, 가슴, 허리, 밑위, 밑단)
   - 공식 상세페이지 URL (게시물에 출처로 적습니다)
   - 세탁·관리 표기 (필요한 경우)

2. 이미지 자료
   - 실물 사진: 앞·뒤·옆, 디테일(단추·포켓·라벨), 색상별
     → 생성할 때 참고용으로만 쓰고, 그대로 재게시하지 않습니다.
   - 사용해도 되는 로고 파일과 사용 조건
   - 실물 샘플 발송 여부 (선택)

3. 사용 목적과 범위
   - 결과물을 쓰실 매체: 자사몰·상세페이지 / 브랜드 SNS / 광고 소재 / 오프라인 / 기타
   - 사용 기간과 시작일
   - 파트너십 광고(도하 게시물로 광고 집행) 계획: 기간, 대략의 광고비 상한
   - 동종 카테고리 독점이 필요한지

4. 표현 가이드
   - 꼭 넣고 싶은 메시지
   - 쓰면 안 되는 표현 (경쟁사 언급, 특정 단어 등)
   - 효능·기능 문구가 있다면 그 근거 자료
     → 도하는 제품을 직접 써 본 것처럼 말하지 않습니다. "입어 보니" 같은 후기 대신 실측·소재에 근거한 코디 제안으로 씁니다.

5. 승인 절차
   - 승인 담당자와 단계 (시안 → 최종)
   - 피드백 회신까지 걸리는 기간
   - 확인 방식 (메일 / 링크 / 회의)

6. 표시 문구 확인
   아래 표시는 법과 플랫폼 정책에 따라 꼭 들어갑니다. 빼거나 줄일 수 없는 점 양해 부탁드립니다.
   - 캡션 첫 두 줄:
     "[광고 · {브랜드명}] AI 기반으로 생성된 가상인물이 포함된 게시물입니다."
     "{브랜드명}(으)로부터 {원고료 · 제작비 · 원고료와 제품}을(를) 받아 제작한 게시물입니다."
   - 도하가 나오는 모든 장: "AI 가상인물" 표시
   - 제품 이미지 안내: "AI 합성 이미지로 실제 제품과 색·핏이 다를 수 있어요. 실물은 브랜드 공식 페이지에서 확인하세요."
   - 인스타그램 '유료 파트너십' 라벨에 태그할 브랜드 계정: @{브랜드 계정}
   - 릴스 음원: 상업 이용이 허가된 음원만 씁니다. 지정 음원이 있다면 권리 확인 자료와 함께 보내 주세요.

7. 일정과 정산
   - 희망 게시일 / 납품일
   - 세금계산서 수신 정보, 정산 담당자 연락처

8. (선택) 참고 질문
   - 지금은 모델 착용 컷을 어떻게 만들고 계신가요? 대략의 빈도나 비용을 알려 주시면 범위를 맞추는 데 도움이 됩니다.

받은 자료를 바탕으로 제안서와 견적서를 {N}영업일 안에 보내드리겠습니다.
감사합니다.
{운영자 이름} 드림 · @doha.dailyfit · {협업 이메일}
```
