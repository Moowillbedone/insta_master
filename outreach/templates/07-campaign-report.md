# 캠페인 성과 리포트

**언제 쓰나**
- 협찬·유료 게시물을 올린 브랜드에 보낸다.
- 24시간 리포트는 짧게(2장 표의 24h 열만), 7일 리포트는 이 틀 전체로 보낸다.
- 7일 기록 후 1~2일 안에 보낸다. 리포트는 다음 제안을 여는 기회다 (6장).

**숫자는 어디서 가져오나**
- `tracking/metrics.csv`의 해당 `post_id` 행이다. `checkpoint`가 `24h`, `7d`인 행을 쓴다.
  - 열: `reach`, `views`, `likes`, `comments`, `saves`, `shares`, `profile_visits`, `follows`, `link_clicks`, `avg_watch_sec`, `completion_rate`
  - `format`이 `carousel`과 `reel`로 나뉜다. `format: both` 게시물이면 표를 두 개 만든다.
- 기록 방법은 둘 중 하나다.
  - 앱 인사이트를 보고 직접 입력한다.
  - 프로페셔널 전환과 토큰 설정 뒤 `python doha.py insights`로 자동 기록한다. 이 명령이 채우지 않는 값(`link_clicks`, `completion_rate`)과 API가 돌려주지 않아 빈 칸으로 남은 값은 앱에서 채운다.
- API 인사이트는 최대 48시간 늦게 반영된다 [확인]. 24h 수치는 나중에 바뀔 수 있다고 적는다. (근거: docs/research/ig-platform.md §6-3)
- API의 좋아요·댓글·조회·총 상호작용은 오가닉 수치만 집계한다 [확인]. 파트너십 광고 성과는 브랜드 광고 관리자 기준이다. (근거: docs/research/ig-platform.md §6-3)
- `impressions`는 2025년에 폐지됐다 [확인]. `views`를 쓴다. (근거: docs/research/ig-platform.md §6-3)

**규칙**
- 기록된 숫자를 고치거나 반올림해서 부풀리지 않는다. 빈 값은 "—"로 둔다.
- 기준선은 내 최근 게시물의 7d 중앙값이다. 몇 개를 썼는지 적는다.
- '인사이트(해석)'는 추정이라고 밝힌다. 판매·전환 효과를 단정하지 않는다.
- 댓글 작성자 아이디 같은 개인 정보는 캡처와 본문에서 가린다.

**인사이트 캡처 첨부**
- 24h, 7d 각각 게시물 인사이트 화면을 캡처한다. 날짜가 보이게 한다.
- 파일 이름: `{post_id}_{24h|7d}_{carousel|reel}.png`
- 캡처는 게시물 폴더 `content/posts/{post_id}/`에 함께 보관한다.

```markdown
# {브랜드명} × 도하 캠페인 리포트 ({24h | 7d})

- 게시물: {post_id} · {게시물 URL} · 게시 {YYYY-MM-DD HH:MM}
- 형식: {카드뉴스 N장 / 릴스 N초}
- 보고일: {YYYY-MM-DD}
- 집계 기준: 인스타그램 인사이트, 오가닉(광고 제외). 24h 수치는 나중에 반영되는 데이터로 바뀔 수 있습니다.

## 1. 요약

- {핵심 숫자 1개: 예) 7일 도달 {N}, 저장 {N} (저장률 {N}%)}
- {기준선 대비: 높음 / 비슷 / 낮음}
- {다음 제안 한 줄}

## 2. 지표 — {카드뉴스 | 릴스}

| 지표 | metrics.csv 열 | 24h | 7d | 도하 기준선 (최근 {N}개 7d 중앙값) |
|---|---|---|---|---|
| 도달 | reach | {N} | {N} | {N} |
| 조회 | views | {N} | {N} | {N} |
| 좋아요 | likes | {N} | {N} | {N} |
| 댓글 | comments | {N} | {N} | {N} |
| 저장 | saves | {N} | {N} | {N} |
| 공유 | shares | {N} | {N} | {N} |
| 프로필 방문 | profile_visits | {N} | {N} | {N} |
| 팔로우 | follows | {N} | {N} | {N} |
| 링크 클릭 | link_clicks | {N 또는 —} | {N 또는 —} | {N} |
| 평균 시청 시간 (초, 릴스) | avg_watch_sec | {N 또는 —} | {N 또는 —} | {N} |

| 공유율 | shares ÷ reach | {N}% | {N}% | {N}% |

‹ format: both 이면 위 표를 릴스용으로 한 번 더 만든다 ›

## 3. 첨부한 인사이트 캡처

- {post_id}_24h_{format}.png
- {post_id}_7d_{format}.png

## 4. 표시·준수 확인

- [ ] 캡션 첫 줄에 광고 표시와 가상인물 고지가 있었다.
- [ ] 도하가 나오는 모든 장·장면에 "AI 가상인물" 배지가 있었다.
- [ ] 유료 파트너십 라벨로 @{브랜드 계정}을 태그했다.
- [ ] (릴스) 시작과 끝에 광고 자막, AI 정보 라벨이 있었다.
- [ ] 사용경험 표현이 없었다.
- [ ] 제품 정보는 공식 출처와 확인일 기준이었다.
```
