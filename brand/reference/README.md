# 얼굴 기준 이미지 (`brand/reference/`)

도하의 얼굴을 모든 게시물에서 같은 사람으로 보이게 하는 기준 사진을 두는 곳이에요.

- `python doha.py generate` 는 여기 있는 이미지를 OpenAI `images.edit` 에 함께 보내요 (`input_fidelity=high`, 모델이 지원할 때).
- `python doha.py prompts` 가 만드는 `prompts.md` 는 ChatGPT 앱에서 이 이미지를 첨부하라고 안내해요.
- 실제로 쓰이는 목록은 `brand/doha.yaml` 의 `visual.face_reference` 예요. 폴더에 넣기만 하면 쓰이지 않아요.

## 지켜야 할 것

- **AI로 만든 도하 이미지만** 넣어요. 연예인·모델·지인·본인 사진, 인터넷에서 받은 사진은 넣지 않아요.
  실존 인물을 닮게 만들면 초상권·퍼블리시티권 문제가 생기고, '가상인물' 표시 원칙과도 어긋나요.
- 기준 이미지는 **사람이 승인**한 뒤에만 `face_reference` 에 올려요.
- 한번 정한 세트는 바꾸지 않아요. 바꾸면 계정 속 인물이 다른 사람이 돼요.
  꼭 바꿔야 하면 새 번호로 추가하고, 이전 파일은 지우지 말고 목록에서만 빼요.

## 처음 만드는 순서 (비용 0원 경로)

1. 기준 사진용 프롬프트 3개를 출력해요 (`brand/doha.yaml` 의 인물 묘사가 그대로 들어가요).

   ```
   python doha.py prompts --reference
   ```

2. ChatGPT 앱에서 **정면(01)** 프롬프트를 새 채팅에 붙여넣고, 3~5번 다시 만들어 후보를 모아요.
3. 아래 체크리스트로 한 장을 고르고 `brand/reference/doha-face-01.png` 로 저장해요.
4. **3/4 각도(02)**, **상반신(03)** 은 01을 첨부한 채로 만들어요. 프롬프트 앞에
   "Same person as the attached photo." 를 한 줄 붙이면 얼굴이 덜 바뀌어요.
5. `brand/doha.yaml` 을 고쳐요.

   ```yaml
   face_reference: [brand/reference/doha-face-01.png, brand/reference/doha-face-02.png, brand/reference/doha-face-03.png]
   ```

6. 확인: `python doha.py prompts <게시물>` 의 '첨부' 항목에 파일이 나오고,
   `python doha.py generate <게시물> --dry-run` 에 `edit + 기준 3장` 이 보이면 연결된 거예요.

## 좋은 기준 사진 체크리스트

- [ ] 얼굴이 크고 선명해요 (긴 변 1024px 이상, PNG).
- [ ] 정면 또는 살짝 옆(30° 이내), 눈을 뜨고 입은 다문 자연스러운 표정.
- [ ] 부드럽고 고른 빛. 강한 그림자·역광·색 조명이 없어요.
- [ ] 단색 배경, 다른 사람·글자·로고가 없어요.
- [ ] `identity` 와 맞아요: 어깨 길이 C컬 갈색 머리, 옆가르마, 아몬드형 눈, 일자 눈썹.
- [ ] **왼쪽 눈 아래 작은 점**이 그녀의 왼쪽(보는 사람 기준 오른쪽)에 있어요. 좌우 반전된 이미지는 쓰지 않아요.
- [ ] 28세 정도 성인으로 보여요. 지나치게 어려 보이거나 인형 같지 않아요.
- [ ] 피부결이 보이고 필터·과보정이 없어요.
- [ ] 얼굴을 가리는 것(손, 머리카락, 안경, 모자)이 없어요. 장신구는 작은 금 귀걸이만.
- [ ] 특정 연예인을 닮지 않았어요 (닮았다는 의견이 하나라도 나오면 버려요).

## 몇 장이 좋은가요?

2~3장 (정면 + 3/4 + 상반신)이면 충분해요. 많이 넣을수록 API 입력 비용이 늘고
(`generate` 는 1장당 약 $0.01을 추정치에 더해요) 효과는 크게 늘지 않아요.

## 파일 규칙

- 이름: `doha-face-01.png`, `doha-face-02.png` … 두 자리 번호. 기존 파일은 덮어쓰지 않아요.
- 형식: PNG 또는 JPG, 50MB 미만 (API 제한).
- 이 이미지들은 git에 올라가요. AI로 만든 도하 이미지 외에는 넣지 마세요.
