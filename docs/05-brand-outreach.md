# 브랜드 영업 가이드: @doha.dailyfit

- 기준일: 2026-10-13 (KST)
- 대상: 1인 운영자
- 함께 볼 문서: [01-monetization-playbook.md](01-monetization-playbook.md) (가격·단계), [04-compliance-checklist.md](04-compliance-checklist.md) (게시물 표시), `outreach/templates/` (문안), `outreach/prospects.csv` (파이프라인)

> **세 가지 원칙**
> 1. **수동·개별.** 한 브랜드씩 직접 조사하고 직접 보낸다. 자동 수집, 자동 DM, 대량 발송은 하지 않는다.
> 2. **먼저 밝힌다.** 인사와 자기소개 바로 다음 문장에서 도하가 AI 가상인물이라고 말한다.
> 3. **제작물을 판다.** 팔로워 도달보다 "AI 룩북 컷 + 사용권"을 먼저 제안한다.

신뢰도 태그는 research 파일의 표시를 그대로 옮긴다: [확인] 공식 1차 / [보도] 2차 / [주장] 업체·블로그 / [미확인] / (해석) research 파일의 판단.

## 2. 브랜드 조사 방법 (수동)

### 2-1. 하지 않는 것

- 크롤러, 자동 수집 프로그램, 대량 저장 도구를 쓰지 않는다. 승인받지 않은 방식으로 정보를 모으면 계정이 제한될 수 있다 [확인]. (근거: research/ig-platform.md §6-5)
- 직원 개인 계정, 개인 휴대폰 번호 같은 개인 연락처는 기록하지 않는다. 공개된 공식 창구만 쓴다. (이 문서의 원칙)

### 2-2. 브랜드 1곳 조사 순서 (목표 15~20분, 운영 기준)

1. **자사몰**
   - 상세페이지에 모델 착용 컷이 몇 장인지 본다.
   - 실측표와 소재 혼용률이 있는지 본다.
   - 가격대와 신상품 업데이트 주기를 본다.
2. **공식 인스타그램**
   - 최근 게시 빈도를 본다.
   - 기존 협업 게시물에 광고 표시가 있는지 본다. 표시 없이 광고해 온 곳은 '보류'로 둔다.
3. **협업 창구**
   - 자사몰 하단의 제휴·협업 문의 메일
   - 웹사이트 문의 폼
   - 인스타그램 프로필의 이메일 버튼
4. **제안할 아이템 1개 고르기**
   - 도하 시리즈(돌려입기, 컬러공식, 비율, 상황별, 아이템가이드)에 바로 들어갈 아이템을 고른다 (content/SCHEMA.md `pillar`).
   - "어떤 아이템을 왜"를 한 문장으로 `fit_reason`에 적는다.
   - 착용 경험처럼 쓰지 않는다. 공식 정보로만 쓴다. 예: "허리 밴딩 + 울 혼방 와이드 슬랙스, 셔츠·니트 모두 매치 가능".
5. **위험 신호 확인** → 하나라도 있으면 '보류'
   - 효능·기능을 강조하는 광고가 많다.
   - 체험단 모집이 주된 마케팅이다.
   - 실측·소재 정보가 없다.
6. **`outreach/prospects.csv`에 기록한다.**

### 2-3. `prospects.csv` 열 작성법

| 열 | 쓰는 법 | 예 |
|---|---|---|
| `brand` | 브랜드 공식 표기 | {브랜드명} |
| `category` | 오피스룩 / 가방 / 신발 / 액세서리 등 | 오피스룩 |
| `instagram` | 공식 계정 핸들 | @{공식 계정} |
| `website` | 자사몰 주소 | {URL} |
| `price_tier` | 대표 아이템 가격대. 공식 페이지 기준 | {가격대} |
| `fit_reason` | 아이템 1개와 이유 1문장 | {아이템} — {이유} |
| `contact_channel` | 이메일 / 폼 / DM | 이메일 |
| `priority` | A / B / C (1-2) | A |
| `status` | 7장의 상태 값 중 하나 | 조사완료 |

## 3. 연락 채널 우선순위

| 순위 | 채널 | 템플릿 | 규칙 |
|---|---|---|---|
| 1 | 공식 협업 문의 이메일 | `02-first-email.md` | 미디어킷 첨부. 한 통에 한 브랜드. 숨은참조 대량 발송 금지 |
| 2 | 웹사이트 문의 폼 | `02-first-email.md` 본문을 폼 길이에 맞게 줄임 | 첨부가 안 되면 미디어킷 링크 |
| 3 | 브랜드 공식 계정에 수동 DM | `01-first-dm.md` | 이메일·폼이 없을 때만. 한 번에 한 곳, 직접 입력 |

**하지 않는 것**
- 먼저 보내는 DM을 자동화하거나 대량으로 보내지 않는다. 공식 API로도 할 수 없고 제재 위험이 크다. (근거: research/ig-platform.md §6-5 [주장])
- 브랜드 게시물 댓글로 영업하지 않는다.
- 동의 없이 상업 목적으로 반복 연락하지 않는다. 커뮤니티 가이드라인 금지 항목이다 [확인] (2019년 제출본이라 현행 문구는 다를 수 있다). (근거: research/ig-platform.md §6-5)
- 같은 브랜드에 채널을 바꿔 가며 중복으로 연락하지 않는다.

## 4. 연락 주기

| 시점 | 행동 | 템플릿 | `status` |
|---|---|---|---|
| D0 | 1차 연락 | 01 또는 02 | 연락 |
| D5~7 | 팔로업 1. 새 정보 한 가지만 더한다 | 03-A | 연락 |
| D12~14 | 마무리 메시지 | 03-B | 보류 |
| 회신이 오면 | 1영업일 안에 답한다. 관심이 있으면 브리프를 요청한다 | 08 | 회신 |
| 범위를 논의하면 | 제안서와 견적서 | 04, 05 | 협의 |
| 보류 후 다음 분기 | 새 시즌 아이템으로 1회만 재연락할 수 있다. 이번에도 답이 없으면 더 연락하지 않는다 | 02 | 연락 |

**규칙**
- 거절을 받으면 다시 연락하지 않는다.
- 팔로업은 최대 2회(03-A, 03-B)다.
- 신규 연락은 주 5곳 안팎으로 한다. 한 곳씩 맞춤으로 쓰기 위해서다. (이 문서의 기준)
- 연락할 때마다 `last_contact`와 `next_action`을 바로 갱신한다.

## 5. 보낼 것

### 5-1. 미디어킷

```
python doha.py media-kit
```

보내기 전에 확인한다.
- [ ] 지표가 실제 값이고, 기준일이 적혀 있다.
- [ ] 도하가 AI 가상인물이라는 문장이 첫 화면에 있다.
- [ ] 추정치나 목표치가 실적처럼 보이지 않는다.
- [ ] 연락처가 협업용 이메일이다.

### 5-2. 샘플 게시물 2~3개

- 브랜드 아이템과 가까운 카테고리의 게시물을 고른다.
- 저장/도달, 공유/도달이 내 기준선보다 높은 게시물을 우선한다 (`python doha.py metrics`).
- 게시물 링크로 보낸다. 실제로 게시된 것만 보낸다.

### 5-3. 무료 시안 1컷 제안

| 단계 | 할 일 |
|---|---|
| 1. 제안만 한다 | 첫 연락에서 "원하시면 {제품명}(으)로 시안 1컷을 무료로 만들어 드릴게요"라고만 쓴다 |
| 2. 동의를 받는다 | 브랜드가 원할 때만 만든다 |
| 3. 자료를 받는다 | 실물 사진과 실측을 받아 그 기준으로 생성한다 (근거: research/kr-compliance.md §4-1, (해석)) |
| 4. 비공개로 보낸다 | 도하 계정이나 포트폴리오에 게시하지 않는다 |
| 5. 쓰려면 계약한다 | 브랜드가 시안을 쓰려면 사용권 계약이 필요하다고 함께 적는다 |
| 6. 비용을 기록한다 | 시안용 폴더를 `--slug spec-{브랜드 영문}`로 만든다 (`python doha.py new "{브랜드명} 시안" --date YYYY-MM-DD --slug spec-{브랜드 영문}`). `generate`가 그 id로 `tracking/costs.csv`에 비용을 자동 기록한다 |

**이유**
- 협찬받지 않은 브랜드의 로고를 AI로 재현해 제휴한 것처럼 보이게 하면 안 된다. (근거: research/kr-compliance.md §5-3, (해석))
- 완성된 협업 사례가 없으면 '가상 협업 시안'을 포트폴리오에 넣지 않는다. (근거: research/ig-platform.md '운영에 바로 쓰는 결론')

## 6. "AI 가상인물" 반론 FAQ

브랜드 질문에 그대로 쓸 수 있는 정직한 답이다. 근거가 없는 효과는 약속하지 않는다.

**Q1. 실제 사람이 아닌데 광고 효과가 있나요?**
- 솔직히 확실한 답은 없다.
- 국내 연구 결과는 엇갈린다. 의인화·매력은 구매의도를 높이고 불쾌감은 낮춘다는 연구(2023)가 있지만, 불쾌감도 구매의도를 높였다는 연구(2025)도 있다. 표본도 작다 [확인] (학술지). (근거: research/sponsorship-kr.md §4-2)
- 답: "효과를 약속드리지는 않습니다. 대신 실제 지표를 24시간·7일 리포트로 드리고, 상세페이지용 컷처럼 결과물 자체로 판단하실 수 있는 형태를 제안드려요."

**Q2. 법적으로 문제는 없나요?**
- 2026-06-01부터 공정위 「추천·보증 등에 관한 표시·광고 심사지침」이 AI 가상인물을 추천·보증 주체에 넣었다. 광고에는 "가상인물" 표시가 필요하다 [확인]. (근거: research/kr-compliance.md §1-1, §1-5)
- 법적 책임은 광고주에게 있다는 해설이 있다 [보도]. (근거: research/ig-platform.md §3-3)
- 답: "표시는 제가 처리합니다. 도하가 나오는 모든 장에 '가상인물' 표시, 캡션 첫 줄 광고 표시, 유료 파트너십 라벨까지 넣어요. 표시를 지키는 크리에이터가 브랜드 리스크도 낮습니다."

**Q3. 도하가 직접 입어 본 후기처럼 써 줄 수 있나요?**
- 안 된다. 가상인물임을 밝혔어도 사용경험에 근거한 것처럼 표현하면 부당광고가 될 수 있다 [확인]. (근거: research/sponsorship-kr.md §4-1)
- 답: "후기 형식은 할 수 없어요. 대신 공식 실측·소재를 근거로 '이렇게 매치하면 ~' 형식의 스타일링 제안을 드립니다. 실제 착용 후기가 필요하시면 실제 사람의 후기로 따로 진행하시는 게 맞습니다."

**Q4. 실제 옷과 다르게 보이면 어떡하나요?**
- AI 이미지가 실물과 다르게 오인되면 허위광고로 판단될 수 있다 [보도]. (근거: research/kr-compliance.md §4-1)
- 답: "실물 사진과 실측을 기준으로 만들고, 브랜드 승인 전에는 게시하지 않습니다. 색·핏이 다를 수 있다는 안내 문구도 넣어요."

**Q5. 이미지 저작권은 누구 것인가요?**
- AI가 만든 결과물은 저작권 보호가 불확실하다 [보도]. (근거: research/kr-compliance.md §5-2)
- 답: "원본 파일과 도하 캐릭터 권리는 운영자인 제가 갖고, 브랜드에는 정한 매체·기간 동안 쓰실 수 있도록 이용을 허락해 드립니다. 독점이 필요하시면 독점 조항을 따로 넣을 수 있어요." (근거: research/sponsorship-kr.md §5-2, (해석))

**Q6. 팔로워가 적은데요?**
- 답: "맞습니다. 그래서 게시 노출보다 상세페이지·룩북용 제작물을 먼저 제안드려요. 게시는 선택이고, 실제 지표를 그대로 공유드립니다."
- 근거: 팔로워 1만 미만에서는 게시비 중심 모델이 성립하지 않는다 (근거: research/sponsorship-kr.md §2-2, (해석))

**Q7. 도하 얼굴이 실제 누군가를 닮았으면요?**
- 답: "실존 인물 사진을 레퍼런스나 얼굴 합성에 쓰지 않고, 생성 기록을 보관합니다."
- 근거: research/kr-compliance.md §5-1 (해석). 정기적인 역이미지 검색 점검도 같은 절에 있다.

**Q8. 저희가 광고로 돌릴 수 있나요? (파트너십 광고)**
- 가능하지만 도하가 먼저 프로페셔널 계정으로 전환해야 한다. (근거: research/sponsorship-kr.md §6 [주장])
- 답: "사용권과 별도 항목으로 권한을 드립니다. 시작일·종료일과 광고비 상한을 계약서에 적어요. 게시물을 보관해도 권한이 켜져 있으면 광고가 계속될 수 있어서 종료일이 꼭 필요합니다." (근거: research/sponsorship-kr.md §6 [확인])

**Q9. 뷰티나 식품도 되나요?**
- 식품표시광고법 개정으로 AI로 만든 전문가의 보증·추천 광고가 금지되고, 2026-11-27 시행된다 [보도]. 화장품법도 같은 취지로 개정됐다 [보도]. (근거: research/kr-compliance.md §4-2)
- 답: "지금은 패션·잡화에 집중하고 있습니다. 뷰티·식품은 도하를 전문가처럼 보이게 하거나 효능 체험을 표현할 수 없어서 맡지 않고 있어요."

**Q10. AI 표시 때문에 소비자가 거부감을 갖지 않을까요?**
- 표시는 선택이 아니다. 인스타그램은 AI로 만든 인물이 나오는데 'AI 생성 프로필' 라벨을 달지 않은 계정의 추천 노출을 제한한다 [보도]. (근거: research/ig-platform.md §3-2)
- 2025~2026년 한국 브랜드·소비자의 가상인물 인식 설문은 찾지 못했다 [미확인]. (근거: research/sponsorship-kr.md §4-3)
- 답: "광고에는 법에 따라 '가상인물' 표시를 해야 하고, 인스타그램도 AI 인물 계정이 라벨을 달지 않으면 추천 노출을 제한한다고 알려져 있어요. 숨기지 않는 것이 신뢰를 지키는 방법이라고 생각합니다."

**Q11. 자격 있는 스타일리스트인가요?**
- 답: "도하는 AI 가상인물이고, 자격증이 있는 전문가가 아닙니다. 코디 제안은 색·비율·소재 같은 이유를 붙여서 드려요."
- 근거: 지침 예시에 '가상의 전문가'가 있다 [보도]. 자격을 암시하는 표현은 피한다 (해석). (근거: research/kr-compliance.md §1-5)

## 7. 딜 흐름 상태 (`prospects.csv`의 `status`)

`후보 | 조사완료 | 연락 | 회신 | 협의 | 계약 | 보류 | 거절`

| 상태 | 뜻 | 들어가는 조건 | `next_action` 예 | 템플릿 | 나가는 조건 |
|---|---|---|---|---|---|
| 후보 | 이름과 주소만 적음 | 발견 | 날짜 + "조사" | — | 2장 조사 완료 → 조사완료. 우선순위 C → 후보 유지 |
| 조사완료 | `fit_reason`, 채널, `priority`를 채움 | 2-2 절차 완료 | 날짜 + "1차 연락" | 01, 02 | 발송 → 연락 |
| 연락 | 1차 또는 팔로업을 보냄 | 발송 | 날짜 + "팔로업(03-A)" | 03 | 답 → 회신. 무응답 2주 → 보류. 거절 → 거절 |
| 회신 | 관심·질문이 담긴 답이 옴 | 회신 수신 | 날짜 + "브리프 요청" | 08 | 범위 논의 시작 → 협의 |
| 협의 | 범위·견적을 논의 중 | 브리프 수령 | 날짜 + "제안서·견적 발송" | 04, 05 | 서명·발주 → 계약. 중단 → 보류 또는 거절 |
| 계약 | 계약서 서명 또는 발주 확정 | 06 체크리스트 통과 | 날짜 + "시안 / 게시 / 리포트 / 정산" | 06, 07 | 상태는 '계약'으로 두고 `notes`에 진행 단계를 적는다 (예: `[정산완료]`) |
| 보류 | 무응답, 시기 미정, 적합성 의문 | — | 재검토 날짜 | — | 재연락 → 연락 |
| 거절 | 브랜드가 거절했거나, 운영자가 레드라인 때문에 거절 | — | 비워 둠 | — | 종료. 다시 연락하지 않는다 |

**`notes` 거절·보류 사유 태그**

`[예산]` `[AI거부]` `[시기]` `[적합성]` `[무응답]` `[레드라인]`

- 월간 리뷰에서 사유별 건수를 센다. 01-monetization-playbook.md 8장.
- `[AI거부]`가 많으면 6장 FAQ와 첫 문장을 고친다.

**계약 뒤 기록**
- `tracking/revenue.csv`: 계약 한 건도 항목별로 행을 나눈다. `type`은 제작비 `production`, 사용권 `usage_rights`, 게시비 `sponsorship`, PA 권한은 `other`(+ `notes`에 "PA 권한")다 (tracking/README.md 3장).
- `tracking/metrics.csv`: 게시했다면 24h·7d 기록 → 07 리포트
- 사용권·PA 권한 종료일을 `next_action`에 적어 둔다 (만료 30일 전 연장 제안).

## 8. 레드라인

아래 요청은 거절하고 `status`를 '거절', `notes`에 `[레드라인]`으로 적는다.

| 하지 않는 것 | 근거 |
|---|---|
| 체험단형 후기, "입어 보니/써 보니" 표현 | 가상인물의 사용경험 표현은 부당광고가 될 수 있다 [확인] (research/sponsorship-kr.md §4-1). 브랜드 문체 규칙 (brand/doha.yaml `voice.rules`) |
| 효능·기능 주장 (예: "체형 보정", "피부가 좋아져요") | 브랜드가 근거를 가진 문구만 쓰고, 근거 책임은 브랜드에 둔다 (research/sponsorship-kr.md §5-2, (해석)) |
| 뷰티·식품·건기식 협찬 (특히 2026-11-27 이후) | AI 전문가 보증 광고 금지 [보도], 효능 체험 표현 금지 (해석) (research/kr-compliance.md §4-2) |
| 도하를 자격 있는 전문가처럼 소개 | '가상의 전문가' 예시 [보도] (research/kr-compliance.md §1-5) |
| 광고·가상인물 표시를 빼거나 줄이거나 '더보기' 아래로 옮기기 | 캡션 첫 줄과 이미지 안 표시. '더보기'·댓글 표시는 부적절 [확인] (research/kr-compliance.md §1-2) |
| 실존 인물(연예인·인플루언서)을 닮게 만들어 달라는 요청 | 퍼블리시티권 위험 (research/kr-compliance.md §5-1) |
| 계약하지 않은 브랜드의 로고·제품을 제휴처럼 보이게 쓰기 | research/kr-compliance.md §5-3 (해석) |
| 브랜드 룩북 사진을 그대로 재게시 | 2026-04-30부터 사진·캐러셀도 독창성 규칙 대상 [보도] (research/ig-platform.md §5) |
| 자동 DM, 대량 DM, 스크래핑, 자동 팔로우·좋아요, 팔로워 구매 | research/ig-platform.md §6-5 |
| 약관을 확인하지 않고 체험단 플랫폼 가입 | AI·가상 계정 허용 여부 [미확인] (research/sponsorship-kr.md §1-3) |
| 종료일 없는 사용권·파트너십 광고 권한 | research/sponsorship-kr.md §5-2, §6 |
| 상업 이용 허가를 확인하지 않은 음원 사용 | research/kr-compliance.md §5-4 |
