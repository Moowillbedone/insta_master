# 도하 인스타그램 수익화·콘텐츠 자동화 마스터 문서

**기준일:** 2026년 10월 13일 (한국시간)  
**계정:** [@doha.dailyfit](https://www.instagram.com/doha.dailyfit/)  
**목표:** AI 가상 스타일리스트 계정을 키우고, 카드뉴스·릴스·브랜드 협업을 통해 검증 가능한 수익을 만드는 운영 체계를 구축한다.

> 월 500만 원은 사용자가 제시한 목표다. 현재 매출이나 보장된 예상 수익이 아니다. 실제 수익은 계정 도달, 타깃 적합성, 브랜드 계약, 판매 전환과 운영비에 따라 달라진다.

## 1. 지금까지 정한 방향

- **계정 콘셉트:** 도하, AI 가상 스타일리스트. 한국어로 출근룩·데일리룩 코디를 돕는다.
- **첫 수익화 경로:** 가상 인물 협찬 광고. 계정과 콘텐츠 데이터를 쌓은 다음 패션·뷰티·라이프스타일 브랜드에 제작물과 게시를 제안한다.
- **보조 수익화:** 제품 링크를 통한 제휴 수수료. 제품 정보를 확인할 수 있고 구매 의도가 높은 콘텐츠에서만 시험한다.
- **콘텐츠 역할:** 릴스는 발견과 도달, 카드뉴스는 저장·공유와 실용 정보 전달을 우선한다. 두 포맷 모두 협찬 제안의 포트폴리오가 된다.
- **사용자가 원하는 제작 수준:** 기존의 단순한 일러스트 대신, 실사 패션 화보처럼 인물·옷·조명·배경이 세련된 이미지. 실제 사람으로 오인시키지 않도록 AI 가상 인물 표시는 유지한다.
- **자동화 목표:** 주제 선정부터 초안, 이미지 제작, 편집, 일정, 성과 기록까지 반복 작업을 줄인다. 품질 검수와 광고 표시 확인은 게시 전에 사람이 한다.

### 추가 조사 요청: X에서 최신 사례 검증

사용자는 X에서 인스타 카드뉴스·AI 가상 인물·협찬 수익 사례를 최신순으로 확인하고, 월 500만 원 이상 수익을 주장하는 계정도 조사해 달라고 요청했다. 이 문서는 사업 방향과 현재 작업 상태를 통합한 문서이며, X 게시물의 최신 링크·게시 시각·수익 증빙을 대조한 조사 결과는 아직 포함하지 않는다. 다음 시장 조사에서는 단순한 수익 주장과 확인 가능한 실적을 구분하고, 반복되는 콘텐츠 포맷·팔로워 규모·수익 경로·자동화 도구를 기록한다.

## 2. 수익 모델: 광고를 사는 것과 광고로 버는 것

| 경로 | 돈의 흐름 | 계정에서의 역할 | 적용 시점 |
|---|---|---|---|
| 브랜드 협찬 게시물 | 브랜드가 콘텐츠 제작·게시 대가를 지급 | 핵심 수익원으로 검증 | 콘텐츠 지표와 포트폴리오 확보 후 |
| 제휴 링크·코드 | 링크나 코드로 발생한 판매의 수수료 | 구매 의도 콘텐츠의 보조 수익 | 추적 링크와 상품 자료를 준비한 뒤 |
| 콘텐츠 제작·사용권 | 브랜드가 제작비 또는 광고 소재 사용권 비용 지급 | 게시 대가와 별도 계약 가능 | 협찬 제안서에서 항목별 합의 |

Meta 광고를 집행하는 것 자체는 수익이 아니라 비용이다. 우리 계정에서 돈을 버는 중심은 브랜드 협찬과 제휴 전환이다. Instagram의 수익 기능과 자격은 계정·지역·시점에 따라 달라질 수 있으므로 앱의 프로페셔널 대시보드에서 확인한다.

월 500만 원 목표는 아래처럼 실제 계약·판매 데이터로 쪼개서 추적한다.

**월 순수익 = 협찬 계약금 + 제작비·사용권 수입 + 제휴 수수료 − 이미지/API·제작·광고 등 운영비**

초기에는 협찬 단가를 임의로 정하지 않는다. 도달, 저장, 공유, 시청 유지, 시청자 구성과 제작 범위를 근거로 제안한다. 게시비, 제작비, 광고 사용권, 사용 기간, 광고 매체비를 각각 구분해 합의한다.

## 3. 카드뉴스와 릴스의 운영 방식

### 카드뉴스

카드뉴스는 계정의 실용성과 저장 가치를 보여주는 형식이다. 단순히 여러 주제를 섞어 많이 올리기보다, 우선 패션·출근룩 안에서 반복 가능한 시리즈를 만든다.

- 코디 조합: 한 벌을 여러 상황에 활용
- 색·비율 팁: 상하의 색 조합, 허리선, 밑단 등
- 상황별 제안: 출근, 약속, 주말
- 제품 비교·추천: 공식 정보를 확인할 수 있는 경우만

각 장의 이미지와 문구를 분리해서 만든다. 이미지 생성 모델에 한글 문구까지 그리게 하지 않고, 사진을 먼저 만든 뒤 편집 과정에서 글자·레이아웃을 얹는다. 이 방식으로 오탈자, 가독성, 브랜드 표기를 관리한다.

### 릴스

릴스는 짧은 시각적 변화와 명확한 첫 문장으로 새 이용자에게 발견될 기회를 만든다. 코디 전환, 세 가지 조합 비교, 계절별 옷장 활용처럼 한 영상에서 한 가지 요점만 전달한다. 이미지·영상 권리와 음원 사용 가능 여부를 확인한다.

### 콘텐츠 실험

초기 제안은 주 4~5개의 독창적 게시물을 시험하는 것이다. 제작 부담이나 품질이 떨어지면 빈도를 낮추고, 지표가 좋은 포맷에 집중한다. 조회수만 보지 말고 저장·공유·프로필 방문·링크 클릭까지 기록한다.

## 4. 실사형 AI 이미지 제작 원칙

- 도하의 얼굴·헤어·분위기를 기준 이미지와 스타일 가이드로 일관되게 유지한다.
- 한국 패션 에디토리얼의 촬영 문법을 쓴다: 자연스러운 자세, 소재 질감, 현실적인 조명·그림자, 세련된 배경과 색보정.
- 한 번에 게시물을 자동 공개하지 않는다. 이미지 생성 → 문구 배치 → 휴대폰 미리보기 → 사실·권리·표기 확인 → 승인된 파일만 게시한다.
- 실제 브랜드 제품이 보이는 경우 모델이 제품의 실제 착용·구매 경험을 했다고 말하지 않는다. 소재·가격·효능은 공식 자료로 확인한다.
- AI 생성 인물이라는 사실을 프로필과 콘텐츠에서 알아볼 수 있게 유지한다. Instagram의 AI 표시도 게시 시 확인한다.
- 인물·의상·배경이 멋져 보이는 것과 사진처럼 설득력 있는 것은 별도 검수 항목이다. 얼굴·손·옷의 구조, 로고·문자 왜곡, 제품 세부 표현을 확인한다.

### 이미지 생성 API 비용과 준비 상태

이미지 생성 API는 사용량에 따라 별도 과금되며 ChatGPT 구독료와 분리된다. OpenAI 공식 비용표의 GPT Image 2 기준으로 **세로 1024×1536 고화질 이미지 1장은 약 $0.165**이며, 문구 입력 비용이 조금 더 붙을 수 있다. 다른 모델·품질 설정은 요청별 사용량을 확인한다. [공식 이미지 생성 비용 안내](https://developers.openai.com/api/docs/guides/image-generation/)

새 API 계정의 선불 결제는 최소 충전액이 $5이고, 자동 충전은 설정 과정에서 기본으로 켜져 있을 수 있으므로 원치 않으면 끈다. 남은 선불 크레딧의 만료·환불 조건도 충전 전에 확인한다. [선불 API 결제 안내](https://help.openai.com/en/articles/8264644-how-can-i-set-up-prepaid-billing)

**현재 상태:** 마지막 로컬 확인에서 이 작업 환경에 OPENAI_API_KEY가 설정돼 있지 않았다. 사용자는 로컬 API 키 사용에 동의했지만 키 설정·결제는 아직 확인되지 않았다. 키를 채팅에 입력하지 않는다. 결제·키 설정 후 우선 이미지 한 장만 시안으로 생성하고, 결과와 API 사용량을 확인한다. 지금까지 이 API를 호출하거나 API 비용을 발생시킨 기록은 없다.

## 5. 광고 투명성과 신뢰

- 도하는 AI 가상 인물이며, 실제 사람의 개인 경험처럼 말하지 않는다.
- 돈·무상 제품·제휴 수수료 등 경제적 이해관계가 있으면 콘텐츠 안에서 명확히 표시하고 Instagram의 유료 파트너십 표시를 사용한다. Instagram은 브랜드 대가뿐 아니라 무상 제공과 제휴 링크도 표시 대상으로 안내한다. [Instagram의 브랜디드 콘텐츠 안내](https://www.facebook.com/help/instagram/616901995832907)
- 한국의 경제적 이해관계 공개 기준은 게시 시점의 공정거래위원회 지침을 확인한다. 현행 행정규칙은 [국가법령정보센터](https://www.law.go.kr/LSW/admRulSc.do?query=%EC%B6%94%EC%B2%9C%E3%86%8D%EB%B3%B4%EC%A6%9D+%EB%93%B1%EC%97%90+%EA%B4%80%ED%95%9C+%ED%91%9C%EC%8B%9C%E3%86%8D%EA%B4%91%EA%B3%A0+%EC%8B%AC%EC%82%AC%EC%A7%80%EC%B9%A8)에서 확인한다.
- Meta는 AI 생성·편집 콘텐츠에 대한 정보 표시를 운영하며 관련 표시 방식은 계속 바뀔 수 있다. 게시 때 앱의 현재 표시 옵션을 확인한다. [Meta의 AI 콘텐츠 표시 안내](https://about.fb.com/news/2024/04/metas-approach-to-labeling-ai-generated-content-and-manipulated-media/)
- 협찬 제안 전에는 브랜드의 제품 설명과 사용 가능한 이미지·영상·음원 권리를 확인한다. 제품을 받았다는 이유만으로 긍정 평가나 실제 체험을 만들어내지 않는다.

## 7. 자동화 단계

**1단계 — 제작 표준화 (진행 중)**  
주제 목록, 캡션 틀, 카드뉴스 템플릿, 릴스 구성, 파일명과 게시 체크리스트를 만든다. 비슷한 작업은 묶어서 제작하되, 업로드 전 사람 검수를 유지한다.

**2단계 — 실사 이미지 생성 (대기)**  
로컬 API 키·결제 준비 후 이미지 시안을 1장 생성한다. 사용자가 결과를 검토한 뒤 얼굴 기준 이미지, 색감, 촬영 톤을 고정하고 릴스·카드뉴스에 적용한다.

**3단계 — 게시 및 성과 기록**  
우선 Instagram 앱에서 직접 게시하고 성과를 운영 보드에 기록한다. 계정 인증이나 허용된 게시 API 연결 없이 자동 게시가 된다고 가정하지 않는다. 무단 DM 자동 발송이나 댓글 스팸은 사용하지 않는다.

**4단계 — 수익화 실험**  
초기 지표가 쌓이면 작은 브랜드 협찬 제안부터 시험한다. 제안서에는 가상 인물 소개, 콘텐츠 사례, 실제 지표, 납품물, 수정 횟수, 게시일, 광고 표시, 사용권 조건을 넣는다. 제휴 링크는 상품 정보·수수료 추적·표시를 갖춘 콘텐츠에서 별도 실험한다.

**5단계 — 확장**  
성과가 검증된 주제와 포맷을 반복하고, 협찬 전환이나 제휴 판매가 확인된 경우에만 유료 광고를 검토한다. 운영량이 안정되면 예약 게시와 분석 자동화의 허용 범위·계정 권한을 다시 확인한다.

## 8. 지표와 의사결정

게시 후 24시간과 7일 시점에 아래를 기록한다.

- 도달 계정과 재생·조회
- 시청 유지·완료 지표(릴스에서 제공되는 범위)
- 저장, 공유, 댓글
- 프로필 방문과 팔로우 변화
- 링크 클릭과 제휴 전환(해당 시)
- 제작 시간과 직접 비용
- 협찬 문의·회신·계약·수익

다음 콘텐츠 주제는 저장·공유·프로필 방문이 만들어졌는지 보고 결정한다. 팔로워 수나 조회수 하나만으로 광고 가치를 주장하지 않는다.

## 9. 다음 실행 순서

1. 프로필의 전문 계정 전환 여부와 대시보드 접근을 확인한다.
2. API 결제·키 설정을 완료한다. 자동 충전이 필요하지 않으면 꺼 둔다.
3. 세로형 실사 패션 화보 시안 한 장을 생성하고 실제 비용을 기록한다.
4. 사용자가 미리보기에서 얼굴·스타일·이미지 완성도를 승인한다.
5. 승인된 방향으로 릴스와 카드뉴스를 새로 만들고, 게시 전 캡션·AI 표시·광고 표시·제품 사실을 검수한다.
6. 게시할지, 기존 두 게시물을 교체할지는 시안을 본 뒤 별도로 결정한다.
7. 성과 자료가 쌓이면 브랜드 제안과 제휴 링크를 순서대로 시험한다.
