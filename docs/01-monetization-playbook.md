## 0. 한 장 요약

1. **돈은 B2B에서 나온다.** 매출의 중심은 제작비와 사용권이다. 파트너십 광고 권한을 추가로 판다. 게시비는 보조다. (근거: research/sponsorship-kr.md §2-2, (해석))
2. **인스타그램 자체 수익 기능은 당분간 0원으로 잡는다.** (근거: research/ig-platform.md '운영에 바로 쓰는 결론')
3. **주력 상품은 "AI 룩북 컷 + 사용권"이다.** 대상은 모델 촬영 비용이 부담되는 소형 여성 오피스룩·잡화 브랜드다. (근거: research/sponsorship-kr.md '운영에 바로 쓰는 결론', (해석))
4. **가격은 공식으로 낸다.** 사용권 가산은 기본 단가의 +20~50%를 시작점으로 잡는다. (근거: research/sponsorship-kr.md §2-1, [주장])
5. **팔로워 1만 미만에서는 게시비만으로 월 500만 원이 불가능하다.** (근거: research/sponsorship-kr.md §2-2, (해석))
6. **Meta 유료 광고는 비용이다.** 전환이 입증된 뒤에만 쓴다. (근거: 00-master-plan.md §2)
7. **제휴는 보조 수입이자 판매 증빙이다.** 처음 6개월 제휴 수수료 `Z`는 월 0~10만 원으로 잡는다. 판매 기록은 협찬·제작비 제안의 근거로 쓴다. (근거: research/affiliate-kr.md §4-2, (해석)) 실행은 [08-affiliate-guide.md](08-affiliate-guide.md).
8. **월 500만 원은 빨라야 12~24개월 차의 상단 시나리오다.** 중간 목표는 6개월 차 월 50만 원, 12개월 차 월 150만 원이다 (추정). 건전한(SFW) 콘텐츠·개인 운영·브랜드 협찬 위주로 월 500만 원을 버는 검증된 사례는 찾지 못했다 [미확인]. (근거: research/market-cases.md §0, §6, '운영에 바로 쓰는 결론' 10. 자세히는 5-6·5-7)

### 1-1. 모든 경로에 공통으로 붙는 조건

- 협찬·제휴 게시물은 세 겹으로 표시한다. ① 캡션 첫 줄 한국어 `[광고]`/`[협찬]` ② 이미지·영상 안 표시 ③ 유료 파트너십 라벨. (근거: research/kr-compliance.md '운영에 바로 쓰는 결론', §1-2 [확인]) 브랜드와 직접 거래가 없는 제휴 프로그램 게시물에도 ③이 필요한지는 [미확인]이다. ①·②는 어느 경우에도 한다. (근거: research/kr-compliance.md §1-7, 08 §4-3)
- 도하가 나오는 모든 장·장면에 도하 가까이 "가상인물" 표시를 한다. 2026-06-01부터 광고에서는 의무다. (근거: research/kr-compliance.md §1-5 [확인])
- 도하가 제품을 직접 써 본 것처럼 표현하지 않는다. 가상인물임을 밝혔어도 부당광고가 될 수 있다. (근거: research/sponsorship-kr.md §4-1 [확인])
- 제휴 링크 수수료도 표시 대상이다. 문구는 "받을 수 있음"이 아니라 "받습니다"로 쓴다. (근거: research/kr-compliance.md §1-3, §1-4 [확인], 문구는 (해석)) 키트가 넣는 줄과 사람이 쓰는 프로그램명 줄은 [08-affiliate-guide.md](08-affiliate-guide.md) 4장.
- 유형별 캡션 템플릿과 게시 직전 체크는 [04-compliance-checklist.md](04-compliance-checklist.md)를 따른다.

## 3. 주력 레버: 제작물 판매

### 3-1. 왜 제작물인가

- 게시비는 팔로워 수에 비례하는 시장 공식으로 매겨진다 [주장]. 지금 도하에게는 작다. (근거: research/sponsorship-kr.md §2)
- 제작비와 사용권은 팔로워 수가 아니라 납품물·기간·매체로 가격을 매긴다. (근거: research/sponsorship-kr.md §2-2, (해석)) 다만 한국 AI 모델 컷 제작 시세는 시장 사례 조사에서도 찾지 못했다 [미확인]. 브랜드가 이 가격을 받아들이는지는 견적 회신으로 확인한다. (확인 필요) (근거: research/market-cases.md '남은 확인 사항')
- 브랜드는 AI 화보로 제작비를 줄이려 한다. LF 헤지스는 제품은 실제로 촬영하고 배경만 AI로 만들어 제작비 약 45%, 기간 절반을 줄였다고 보도됐다 [보도]. 신세계톰보이 보브는 AI로 실사화한 가상 모델을 공개했다 [보도]. (근거: research/market-cases.md §1)
  - 브랜드가 AI 모델을 직접 만드는 흐름이라 "AI 모델을 빌려주는 계정"으로만 경쟁하면 불리하다. **스타일링 기획이 붙은 AI 착용컷 제작**으로 판다 (해석). (근거: research/market-cases.md §1 '함의', §4-1)
- 사용권은 기간이 끝나면 연장이나 확대 제안의 기회가 된다. (이 문서의 판단)
- 브랜드가 제작비를 비교할 대상은 지금 쓰는 모델 촬영 비용이다. 이 금액은 브리프 단계에서 직접 묻는다 (outreach/templates/08-brief-request.md). (확인 필요)

### 3-2. 누구에게 파나

- 모델 촬영 비용이 부담되는 소형 여성 오피스룩·잡화 브랜드. (근거: research/sponsorship-kr.md '운영에 바로 쓰는 결론', (해석))
- 고르는 기준과 조사 방법은 [05-brand-outreach.md](05-brand-outreach.md) 1~2장.
- 후보 49곳(의류 29, 잡화 20 / A 11, B 26, C 12)이 `outreach/prospects.csv`에 있다. 웹 검색만으로 만든 목록이라 연락처는 거의 비어 있고, 연락 전에 앱·공식몰에서 직접 확인해야 한다. 쓰는 법과 A등급 목록은 05 문서 1-3절. (근거: research/brand-prospects-apparel.md, research/brand-prospects-accessories.md)
- 저가 신발 자사몰(바닐라슈, 착한구두)에는 협찬보다 "AI 착용 컷 + 사용권" 제작물 제안이 맞다 (해석). (근거: research/brand-prospects-accessories.md '운영에 바로 쓰는 결론')
- 제휴 판매 기록을 먼저 만들고 그 숫자를 들고 연락하는 '플랫폼 먼저' 순서는 05 문서 1-4절. (근거: research/brand-prospects-apparel.md '운영에 바로 쓰는 결론' 3·4)

2. 게시물 폴더를 만든다.
   ```

   ```

   - `products`: 공식 정보, `source_url`, `checked_at` (없으면 `check`에서 실패)

   - `images.*.outfit`: 브랜드 실측·소재 기준
4. 비용 없이 프롬프트를 먼저 본다.
   ```
   python doha.py prompts <slug>
   python doha.py generate <slug> --only s01 --dry-run
   ```
5. 시안 1컷만 생성한다. 비용이 발생하고, 터미널에서 y를 입력해야 실행된다 (config.yaml `require_confirmation`).
   ```
   python doha.py generate <slug> --only s01
   ```
6. 브랜드가 시안을 승인하면 나머지를 생성한다.
7. 검수와 렌더링을 한 번에 한다. 결과는 휴대폰 미리보기로 확인한다.
   ```
   python doha.py build <slug>
   ```
8. 브랜드가 최종본과 `out/caption.txt`의 표시 문구를 승인하면 납품하거나 게시한다.

### 4-2. 견적 워크시트

**변수**

| 기호 | 뜻 | 어디서 가져오나 |
|---|---|---|
| `R` | 시간당 목표 단가 (원) | 4-3에서 계산 |
| `H_plan` | 기획·브리프 정리 시간 | 내 작업 기록 |
| `H_gen` | 이미지 생성·선별 시간 | 내 작업 기록 |
| `H_edit` | 렌더링·편집·검수 시간 | 내 작업 기록 |
| `H_rev` | 포함 수정 대응 시간 (포함 횟수 × 회당 시간) | 내 작업 기록 |
| `H_comm` | 연락·승인·리포트 시간 | 내 작업 기록 |
| `n_img` | 생성 횟수 (재생성 포함) | 납품 컷 수 × 컷당 평균 생성 횟수. 컷당 평균 = 지난 작업의 `tracking/costs.csv` `quantity` 합계 ÷ 지난 납품 컷 수 |
| `c_img` | 장당 생성비 (원) | 처음에는 config.yaml `est_cost_usd` × `fx.usd_krw`, 이후에는 costs.csv 실제값. 참고: gpt-image-2 1024×1536 출력 비용은 low 약 $0.005, medium 약 $0.041, high 약 $0.165이고 기준 사진 입력 비용이 따로 붙는다 [보도] (research/image-gen-tech.md §1-4) |
| `C_etc` | 기타 직접비 (음원, 소품, 외주 등) | 견적마다 |
| `b` | 재생성 위험 버퍼 (비율) | 첫 3건은 운영자가 정하고, 실측 오차로 고친다 |
| `A_7d` | 최근 게시물의 7일 도달 중앙값 | `tracking/metrics.csv` (`checkpoint` = 7d) |
| `k` | 도달 1,000당 게시 단가 (원) | 운영자가 정하고 4-5의 시장 공식과 비교한다 |
| `u` | 사용권 가산율 | 4-4 표 |
| `a` | 파트너십 광고 권한 가산율 | 사용권 가산율을 기준점으로 (sponsorship-kr.md §6, (해석)) |
| `e` | 독점 가산율 | 운영자가 정한다 (시장 자료 [미확인]) |

**공식**

```text
① 제작비     P_prod = [ (H_plan + H_gen + H_edit + H_rev + H_comm) × R
                       + n_img × c_img + C_etc ] × (1 + b)
② 게시비     P_post = (A_7d ÷ 1,000) × k                 ← 게시가 없는 계약이면 0
③ 기본 단가   P_base = P_prod + P_post
④ 사용권     P_lic  = P_base × u
⑤ PA 권한    P_pa   = P_base × a                         ← 선택
⑥ 독점       P_ex   = P_base × e                         ← 선택
⑦ 공급가액   P      = P_base + P_lic + P_pa + P_ex        (부가세 별도)
⑧ 추가 수정  회당   = 회당 평균 수정 시간 × R
```

**실수령 확인**
- 지급자가 3.3%를 원천징수하는 경우가 많다는 설명이 있다 [주장]. 이때 실수령은 `P × (1 − 0.033)`이다. (근거: research/kr-compliance.md §6)
- 세금계산서 발행, 부가세, 원천징수가 내 사업자 유형에서 어떻게 적용되는지는 세무사와 정한다. (확인 필요)

### 4-3. 시간당 목표 단가 `R` 정하기

```text
R_min = (목표 월 순수익 + 월 고정비) ÷ 월 청구 가능 시간
```

- 목표 월 순수익: 5,000,000원 (config.yaml. 목표이지 예측이 아니다)
- 월 고정비: `tracking/costs.csv`의 월 합계. 이미지 API, 툴 구독, 세무 비용, 광고비를 모두 넣는다.
- 월 청구 가능 시간: 전체 작업 시간에서 자체 콘텐츠·영업·관리 시간을 뺀 값. 실측한다.

`가정` 예시: 월 청구 가능 시간이 80시간이면 `R_min = (5,000,000 + 월 고정비) ÷ 80 = 62,500 + 월 고정비 ÷ 80`원이다.

- `R_min`으로 낸 견적이 시장 비교값(4-5)보다 크게 높으면 가격만 올리지 않는다.
- 대신 ① 제작 시간을 줄이거나 ② 사용권·연장 비중을 늘리거나 ③ 청구 가능 시간을 늘린다.

### 4-4. 사용권 가산율 `u` 표

| 매체 \ 기간 | 1개월 | 3개월 | 6개월 | 6개월 초과 |
|---|---|---|---|---|
| 자사몰·상세페이지 | **+20% (시작점)** | 운영자 결정 | 운영자 결정 | 별도 협의 |
| + 브랜드 SNS 오가닉 | 운영자 결정 | 운영자 결정 | 운영자 결정 | 별도 협의 |
| + 브랜드 광고 소재 (메타 등) | 운영자 결정 | 운영자 결정 | 운영자 결정 | 별도 협의 |
| + 오프라인 (매장·인쇄) | 운영자 결정 | 운영자 결정 | **+50% 이상** | 별도 협의 |

- 가장 좁은 범위(자사몰·상세페이지 1개월)는 +20%, 가장 넓은 범위(오프라인까지 6개월)는 +50% 이상에서 시작한다. (근거: research/sponsorship-kr.md §2-1 [주장], '운영에 바로 쓰는 결론')
- 칸 사이 값은 운영자가 정하고, 계약 데이터로 고친다. 기간·매체별 시장 차등은 [미확인]이다.
- 기간이 끝나면 신규 게재를 멈추고 기존 게재물을 내리는 조항을 둔다. (근거: research/sponsorship-kr.md §5-2, (해석))
- 파트너십 광고 권한(`a`)은 이 표와 따로 받는다. 시작일, 종료일, 광고비 상한을 적는다. 게시물을 보관해도 권한이 켜져 있으면 광고가 계속될 수 있다 [확인]. 그래서 종료일이 꼭 필요하다. (근거: research/sponsorship-kr.md §6)

## 5. 월 500만 원 시나리오 (모두 `가정`, 예측 아님)

### 5-1. 기본 식

```text
월 순수익 = Σ제작비 + Σ(사용권 + PA 권한 + 독점) + Σ게시비 + 제휴 수수료 − 월 비용 C
필요 매출 T = 5,000,000 + C
```

- 식의 출처: 00-master-plan.md §2
- `C`는 `tracking/costs.csv`의 월 합계다.

### 5-2. 게시비만으로는 닿지 않는다

| 팔로워 | 게시물 1건 (시장 공식, [주장]) | 월 500만 원에 필요한 건수 (단순 계산) |
|---|---|---|
| 1,000명 | 1만~1.5만 원 | 약 333~500건 |
| 10,000명 | 10만~15만 원 | 약 33~50건 |
| 마이크로(1만~10만) 평균 44만 원 + 사용권 20~50% | 약 53만~66만 원 | 약 8~10건 |

- 근거: research/sponsorship-kr.md §2-2 (해석). 1,000명 행의 건수는 같은 단가로 이 문서에서 다시 계산했다.
- 팔로워 1만 미만인 지금은 마지막 행도 해당하지 않는다. 그 행의 단가가 1만~10만 구간의 값이기 때문이다.

### 5-3. 역산표: 제작 계약만으로 채운다면

| 월 제작 계약 수 `N` | 필요한 건당 평균 공급가액 (`C` 제외) |
|---|---|
| 1 | 5,000,000원 |
| 2 | 2,500,000원 |
| 3 | 약 1,666,667원 |
| 4 | 1,250,000원 |
| 5 | 1,000,000원 |
| 8 | 625,000원 |
| 10 | 500,000원 |

- 각 행에 `C ÷ N`을 더한다.
- 처리 가능 여부를 함께 본다: `N × 건당 실제 시간 ≤ 월 청구 가능 시간`.
- `가정` 예시: 건당 20시간이면 10건은 200시간이다. 자체 콘텐츠를 만들면서 1인이 처리하기 어렵다.
- 건당 금액이 시장에서 받아들여지는지는 AI 모델 컷 시세 조사 전에는 판단할 수 없다. (확인 필요)

### 5-4. 조합 예시 (`가정`)

| 조합 | 구성 | 계산 | 성립하려면 확인할 가정 |
|---|---|---|---|
| ① 게시비만 | 게시 `M`건 × `Y` | 5-2 표 | 팔로워 1만 미만에서는 성립하지 않는다 |
| ② 제작 중심 | 제작 3건 × `X` + 게시 2건 × `Y` + 제휴 0 | `Y`를 팔로워 1만 기준 10만~15만 원 [주장]으로 두면 `X ≈ 157만~160만 원 + C ÷ 3` | `X`가 시세 안에 드는가 (확인 필요). 월 3건을 처리할 시간이 있는가 |
| ③ 소액 다건 | 제작 6건 × `X` | `X ≈ 83만 원 + C ÷ 6` | 월 6곳과 계약할 파이프라인이 있는가. 6건 처리 시간 |
| ④ 혼합 + 연장 | 제작 2건 × `X` + 사용권 연장 `r`건 × `L` + 게시 `M`건 × `Y` + 제휴 `Z` | `2X + rL + MY + Z = 5,000,000 + C` | `L` = 기존 계약의 `P_base × u`. `Z`는 처음 6개월 월 0~10만 원 (해석, research/affiliate-kr.md §4-2). 목표 대비 비중이 작아 `X`·`L`이 사실상 전부를 채워야 한다 |

**파이프라인 역산**

```text
필요한 1차 연락 수 = 월 계약 목표 N ÷ (회신율 × 회신→계약 전환율)
```

- 두 비율은 아직 데이터가 없다. `outreach/prospects.csv`의 상태 변화로 측정한다.

### 5-5. 시나리오가 기대는 가정과 확인 방법

| 가정 | 확인 방법 |
|---|---|
| 건당 제작비 `X`를 브랜드가 받아들인다 | AI 모델 컷 시세 조사 (확인 필요), 실제 견적 회신 |
| 월 처리 가능 건수 | 건당 실제 작업 시간 기록 |
| 회신율·계약률 | `outreach/prospects.csv` 상태별 건수 |
| 게시비 `Y` | 실제 도달(`metrics.csv`)과 시장 공식 [주장] 비교 |
| 사용권 연장 `L` | 만료 시 연장 제안의 성공률 |
| 제휴 수수료 `Z` | 처음 6개월은 월 0~10만 원 (해석). 첫 게시 전까지는 0. 3개월 실측(클릭→주문 전환율, 확정 수수료)이 쌓이면 바꾼다 (08 §6-4). 근거 계산은 모두 가정이다: 팔로워 1만·월 클릭 1,000·전환율 2%·결제액 6만 원·수수료율 7%·반품 10%면 월 약 75,600원 (research/affiliate-kr.md §4-2) |
| 월 비용 `C` | `tracking/costs.csv` |
| 세금 영향 | 세무사 (확인 필요) |

### 5-6. 시장 사례가 말해 주는 것

| 사실 | 신뢰도 | 근거 |
|---|---|---|
| 언론이 '월 500만 원'을 다룬 국내 AI 인플루언서 사례는 노출 수위를 높인 이미지로 유료 구독(인스타그램 구독·패트리온)을 받는 계정 하나다. 금액도 구독자 수로 낸 **기자 추산**이다 | [보도] | research/market-cases.md §3-1 |
| 건전한(SFW) 콘텐츠·개인 운영·브랜드 협찬 위주로 월 500만 원을 버는 검증된 사례는 찾지 못했다 | [미확인] | research/market-cases.md §0 |
| 국내 개인 운영 AI 인플루언서 인터뷰: 팔로워 약 4만 명에 월 300~400달러 | [보도] | research/market-cases.md §3-1 |
| 아이타나 로페즈(에이전시 운영): 평균 월 약 3,000유로, 브랜드 1건 약 1,000유로. 구독 플랫폼 수익이 섞여 있다 | [주장] | research/market-cases.md §2 |
| 브랜드는 AI 화보 제작비 절감을 원한다: LF 헤지스 제작비 약 45% 절감 | [보도] | research/market-cases.md §1, '운영에 바로 쓰는 결론' 3 |

**교훈**
1. **"월 500만 원 인증" 글을 벤치마크로 쓰지 않는다.** 언론이 다룬 유일한 국내 사례는 성인 지향 구독 모델이고, 금액도 기자 추산이다 [보도]. 고수익 주장은 대부분 강의·전자책 판매와 붙어 있다 (해석). (근거: research/market-cases.md §3-1, '운영에 바로 쓰는 결론' 1)
2. **유료 부업 강의·전자책은 사지 않는다.** 한국소비자원에 접수된 온라인 부업 강의 피해구제 신청은 2024년 11건에서 2025년 42건으로 늘었고, 최근 5년 59건 중 89.8%가 결제액 100만~400만 원 구간이었다 [보도]. (근거: research/market-cases.md §3-3)
   - 수익 인증을 볼 때의 레드플래그 (해석): ① 프로필·고정 게시물에 강의·전자책·오픈채팅 링크 ② 정산 내역이 아니라 캡처·그래프 ③ 팔로워·참여 규모와 계산이 맞지 않음 ④ 수익원이 성인 지향 구독 ⑤ 해외 강의를 번역해 "국내 최초"로 판매
3. **돈은 B2B 제작비에서 나온다는 3장의 판단을 유지한다.** 브랜드의 제작비 절감 수요가 보도로 확인된다. 도하 계정은 "AI 착용컷·카드뉴스 제작 포트폴리오"로 쓴다 (해석). (근거: research/market-cases.md '운영에 바로 쓰는 결론' 3)
4. **해외 사례 수치는 미디어킷·제안서에 넣지 않는다.** 릴 미켈라와 루 두 마갈루는 제3자 추정, 아이타나는 운영사가 밝힌 값이다 [주장]. 도하 자체 지표만 쓴다. (근거: research/market-cases.md '운영에 바로 쓰는 결론' 9)
5. **첫 6개월 KPI는 수익이 아니라 저장·공유율, 프로필 방문, 문의 수다.** 블로그 자료들도 초기 수익을 거의 0으로 본다 [주장]. (근거: research/market-cases.md '운영에 바로 쓰는 결론' 7)

## 8. 월간 리뷰 (매월 첫째 주, 60~90분)

### 8-1. 순서

1. **데이터 마감 (15분)**
   - `tracking/metrics.csv`: 모든 게시물의 24h·7d(필요 시 30d)
   - `tracking/followers.csv`: 주 1회 기록이 빠짐없이 있는지 (tracking/README.md 2장)
   - `tracking/revenue.csv`: 계약 한 건도 항목별로 행을 나눈다. `type`은 제작비 `production`, 사용권 `usage_rights`, 게시비 `sponsorship`, 제휴 `affiliate`, 현물 `gifted`다. PA 권한은 전용 값이 없으므로 `other`로 적고 `notes`에 "PA 권한"을 남긴다 (tracking/README.md 3장).
   - `tracking/costs.csv`: 이미지 API, 툴 구독, 세무, 광고비
   - 제휴 대시보드(지그재그·무신사 등): 플랫폼별 클릭·주문·확정 수수료. 확정분만 `revenue.csv`에 `type=affiliate`로 적고, 확정 전 수치는 아래 기록 양식에만 적는다 (08 §6)
   - `outreach/prospects.csv`: 상태와 `last_contact`
   - 선택: 프로페셔널 전환과 토큰 설정 후 `python doha.py insights`로 지표를 자동 기록할 수 있다.
2. **리포트 실행**
   ```
   python doha.py metrics
   python doha.py board
   ```
3. **질문 8개에 답한다**
   1. 순이익(매출 − 비용)은 얼마이고, 목표와 차이는 얼마인가? 중간 목표(5-7: 6개월 차 월 50만 원, 12개월 차 월 150만 원) 대비로는 어떤가?
   2. 매출 구성은 어떤가? (제작 / 사용권 / PA 권한 / 게시 / 제휴)
   3. 시간당 순이익은 `R_min`보다 높은가?
   4. 저장/도달, 공유/도달 상위·하위 시리즈는 무엇인가?
   5. 상태별 파이프라인 건수, 회신율, 계약률은 어떤가?
   6. 다음 30일 안에 끝나는 사용권·파트너십 광고 권한은 무엇인가? (연장 제안 또는 종료 확인)
   7. `check` 실패 사유와 브랜드 요청 중 거절한 것은 무엇인가?
   8. 제휴 플랫폼별 클릭 → 주문 전환율은 얼마인가? 판매가 생긴 브랜드를 `prospects.csv`에 적었는가? (08 §6-4, 05 §1-4)
4. **결정은 3개 이하로 적는다.** 예: 시리즈 유지·중단, `R` 조정, 타깃 조정.
5. **앱 점검**
   - 프로페셔널 대시보드의 수익화 상태 (근거: research/ig-platform.md '운영에 바로 쓰는 결론')
   - 계정 상태의 추천 가능 여부 (근거: research/ig-platform.md §5)
6. **분기마다 (1·4·7·10월) 규정 변화를 확인한다.** (근거: research/kr-compliance.md '운영에 바로 쓰는 결론')
   - 정보통신망법 개정 (게시자 AI 표시)
   - AI 기본법 개정 (이용자 표시 의무)
   - 과태료 계도기간 종료 (최소 2027-01-22) [보도]
   - 화장품법 개정 시행일. 공포 후 6개월 시행이지만 공포일을 확인하지 못해 시행일은 [미확인]이다 (근거: research/kr-compliance.md §4-2, 검증 메모 3)
   - 제휴 프로그램 요율·약관 변경과 AI 계정 허용 답변 (08 §3-3)
