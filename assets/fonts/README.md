# 폰트

| 파일 | 원본 | 용도 | 라이선스 |
|---|---|---|---|
| Pretendard-{Regular,Medium,SemiBold,Bold,ExtraBold}.woff2 | [Pretendard 1.3.9](https://github.com/orioncactus/pretendard) | 본문·제목 | OFL-Pretendard.txt |
| NotoSerifKR-{500,700}.woff2 | [Noto Serif KR](https://github.com/google/fonts/tree/main/ofl/notoserifkr) 가변폰트에서 고정 굵기로 추출 | 화보형 제목 | OFL-NotoSerifKR.txt |
| CormorantGaramond-{Medium,SemiBold}.woff2 | [Cormorant Garamond](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond) | 영문 워드마크·숫자 | OFL-Cormorant.txt |

폰트 파일만 따로 판매하는 것은 금지되지만, 이 폰트로 만든 이미지와 영상은 상업적으로 써도 됩니다.
